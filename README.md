Authors: Mahesh Kumar, Krunal Pandya, Shrey. Professor: Ing. Petr Benda, Ph.D. Academic year 2026/2027.

## Contents

|---|---|

## Website
Five pages: `index.html`, `destinations.html`, `culture.html`, `adventure.html`, `plan.html`. Contact & Support is a section of Plan Your Trip.
Unzip the website and open `index.html`. It needs no server, libraries or internet connection.

## Where to find this project on GitHub
- **Repository:** https://github.com/maheshmalhi112/Kashmir_Tourism_Website
- **Live website (GitHub Pages):** https://maheshmalhi112.github.io/Kashmir_Tourism_Website/Discover_Kashmir_Website/

```
git clone https://github.com/maheshmalhi112/Kashmir_Tourism_Website.git
```

After downloading, open `website/index.html` in a web browser.

## Notes
Informational prototype only: no backend, bookings, live data or message submission; not an official tourism or safety advisory.
Card sorting was done by the authors; no outside participants were involved.
